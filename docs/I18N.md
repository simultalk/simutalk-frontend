# Idiomas (T-04)

La app usa **ngx-translate**. Los textos están en:

- `public/assets/i18n/es-419.json` (español, idioma por defecto)
- `public/assets/i18n/en-US.json` (inglés)

El selector de idioma está en la barra superior y en el login. El idioma elegido se recuerda en el navegador.

## Convención de claves

```
<contexto>.<pantalla>.<elemento>
```

- **contexto**: la carpeta de su bounded context: `iam`, `profiles`, `recruitment`, `interviews`, `assessment`, `analytics`. Lo común a toda la app va en `shared` y los textos genéricos en `common`.
- **pantalla**: el componente, en camelCase (`jobForm`, `ranking`, `takeInterview`).
- **elemento**: qué es, en camelCase (`title`, `saveButton`, `emptyState`, `nameRequired`).
- Todo en inglés y camelCase. Sin espacios ni tildes en las claves.

Ejemplos:

| Clave | es-419 | en-US |
|---|---|---|
| `recruitment.jobForm.title` | Nueva vacante | New job posting |
| `recruitment.jobForm.saveButton` | Guardar vacante | Save job posting |
| `assessment.ranking.emptyState` | Aún no hay postulantes evaluados | No evaluated candidates yet |
| `common.cancel` | Cancelar | Cancel |

## Cómo traducir tu pantalla

1. Agrega tus claves **en los dos archivos** (`es-419.json` y `en-US.json`), dentro de tu contexto.
2. En tu componente, importa el pipe:
   ```ts
   import { TranslatePipe } from '@ngx-translate/core';
   // ...
   imports: [/* lo que ya tenías */, TranslatePipe],
   ```
3. En el HTML, cambia el texto fijo por la clave:
   ```html
   <h1>{{ 'recruitment.jobForm.title' | translate }}</h1>
   <input [placeholder]="'recruitment.jobForm.namePlaceholder' | translate" />
   ```
4. Con valores variables:
   ```json
   "greeting": "Hola, {{name}}"
   ```
   ```html
   {{ 'profiles.home.greeting' | translate: { name: username } }}
   ```
5. En TypeScript (por ejemplo, un mensaje de error):
   ```ts
   private translate = inject(TranslateService);
   this.translate.instant('recruitment.jobForm.saveError');
   ```

Para evitar conflictos al mergear: cada uno agrega sus claves **solo dentro de su contexto** y no reordena las del resto.
